# Redact, Then Ask

**A privacy-first pipeline for chatting with sensitive documents.**
DATA 622 (Natural Language Processing) · UMBC · Fall 2026

People want to ask an LLM questions about contracts, patient notes and resumes, but those documents are full of names, ID numbers and contact details. Redact, Then Ask finds that personal information, replaces it with consistent placeholders, and only then lets you chat with the document, using a model that runs entirely on your own machine. We also measure what that privacy costs: how much answer quality you lose as redaction gets more aggressive.

```
Before:  John Smith (MRN 448812) was admitted on 03/14/2026. Mr. Smith reported chest pain.
After:   [PERSON_1] (MRN [MRN_1]) was admitted on [DATE_1]. [PERSON_1] reported chest pain.
Ask:     "When was the patient admitted, and what did they report?"
Answer:  "[PERSON_1] was admitted on [DATE_1] and reported chest pain."
```

## How it works

```
 PDF / DOCX / TXT
        │
   1. Ingest ─────────── clean text + character offsets
        │
   2. Language ID ────── lingua (offline)
        │
   3. Classify ───────── resume · contract · medical · email · court case
        │                         │ selects rule pack
   4. Detect PII ─┬─ regex + validators (SSN, card via Luhn, phone, email, IP, IDs)
                  └─ transformer NER (names, orgs, locations, addresses)
        │
   5. Resolve ────────── merge overlapping spans, settle conflicts
        │
   6. Redact ─────────── consistent pseudonyms across mentions
        │
   7. Evaluate ───────── P / R / F1 per PII type vs. gold, vs. Presidio
        │
   8. Chat (RAG) ─────── retrieval over the REDACTED text, local LLM via Ollama
```

Full design: [`docs/PROJECT_DOC.md`](docs/PROJECT_DOC.md). Build status: [`docs/PROGRESS.md`](docs/PROGRESS.md).

## Quickstart

Requirements: Python 3.11, about 6 GB of disk, and [Ollama](https://ollama.com) for the chat feature. A GPU is optional and only used for fine-tuning.

```bash
git clone <repo-url> redact-then-ask && cd redact-then-ask
make setup                      # venv, dependencies, spaCy model
ollama pull qwen2.5:7b-instruct # local LLM for chat (one time)
make data                       # download and convert public datasets
make demo                       # opens the Streamlit app
```

Command line:

```bash
rta redact path/to/file.pdf --mode placeholder --out redacted.txt
rta detect path/to/file.docx --format json
rta chat   path/to/file.pdf      # interactive Q&A over the redacted text
rta eval   --dataset ai4privacy --split test --compare presidio
```

## Results

All numbers are generated by scripts and collected in [`reports/RESULTS.md`](reports/RESULTS.md):

- per-type precision, recall and F1, ours vs. Microsoft Presidio,
- the privacy vs. utility curve across four redaction levels,
- the leak test (does the LLM ever output original PII),
- the error propagation table (which upstream stage costs the most recall).

## Datasets

[ai4privacy/pii-masking-300k](https://huggingface.co/datasets/ai4privacy/pii-masking-300k) · [Text Anonymization Benchmark (TAB)](https://github.com/NorskRegnesentral/text-anonymization-benchmark) · CoNLL-2003 · plus 30 documents hand-labeled by the team. Licenses and download steps are in `data/SOURCES.md`.

## Privacy note

No document text is sent to any external service. The language model runs locally through Ollama. Sample documents in this repo are synthetic; all names, numbers and records are fictional.
